# 📘 Icônes Console pour le Bot Artifact MMO

Utilise ces icônes dans les logs pour rendre la sortie console plus lisible et informative.

---

## ✅ Succès

| Emoji | Signification          | Exemple                            |
|-------|------------------------|------------------------------------|
| ✅    | OK / Terminé           | ✅ Personnage créé                 |
| ✔️    | Action validée         | ✔️ Authentification réussie        |
| 🆗    | Statut OK général      | 🆗 Tous les bots connectés         |
| 🟢    | En ligne / prêt        | 🟢 Serveur disponible              |

---

## 🔄 Processus & Actions

| Emoji | Signification              | Exemple                             |
|-------|----------------------------|-------------------------------------|
| 🔄    | Action en cours / boucle   | 🔄 Déplacement de BotAres           |
| 🔁    | Répétition / Retry         | 🔁 Nouvelle tentative               |
| 🔃    | Rafraîchissement           | 🔃 Mise à jour de l’état            |
| ⏳    | Attente                    | ⏳ Délai avant prochaine action     |
| 🕒    | Cooldown / Timer           | 🕒 Prochaine attaque dans 3s        |

---

## 🆕 Création / Initialisation

| Emoji | Signification               | Exemple                                 |
|-------|-----------------------------|-----------------------------------------|
| 🆕    | Nouveau / Créé              | 🆕 Personnage "BotAthena" créé          |
| 🛠️    | Configuration / Setup       | 🛠️ Initialisation du bot                |
| 📦    | Ressource / Fichier ajouté  | 📦 Cache local mis à jour               |

---

## ⚠️ Avertissement & Erreur

| Emoji | Signification              | Exemple                                  |
|-------|----------------------------|------------------------------------------|
| ⚠️    | Avertissement              | ⚠️ Nom de personnage déjà pris           |
| ❗    | Important à noter          | ❗ Token non défini                      |
| ❌    | Échec / Erreur critique    | ❌ Erreur de création de BotHermes       |
| 🔥    | Crash ou gros souci        | 🔥 Serveur non joignable                 |
| 🛑    | Action interdite/arrêtée   | 🛑 Personnage en cooldown                |

---

## 📊 Information & Debug

| Emoji | Signification              | Exemple                                |
|-------|----------------------------|----------------------------------------|
| ℹ️    | Information                | ℹ️ Token utilisé : ...                 |
| 📋    | Log / Affichage de data    | 📋 Liste des persos : [...]            |
| 📡    | Requête API                | 📡 GET /my/characters                  |
| 🧪    | Test ou Debug              | 🧪 Test du déplacement de BotAres      |
| 📂    | Chargement de fichier      | 📂 Fichier de config lu                |

---

## 💡 Astuce

Pour enrichir encore plus l'affichage console, pense à utiliser une bibliothèque comme [`chalk`](https://www.npmjs.com/package/chalk) pour la colorisation CLI.
